Simple Python project that manages basic hospital records and performs data analytics.
What can it do
1. Add & view patients
2. Add & view doctors
3. Book and update appointments
4. Admit & discharge patients
5. Create bills
6. Export data to CSV
7. Analyze data using Pandas & Matplotlib

Analytics Includes (using Pandas + NumPy + Matplotlib)
1. Total patients & doctors
2. Appointment no-show rate
3. Revenue summary
4.Admission trends
5. Top diagnoses chart

TO RUN:
python meditrack.py
For analytics :
python analytics.py

(Python
JSON file storage
Pandas, NumPy, Matplotlib)
